# Light game artwork generation prompts

Built-in image-generation tool, one edit call per image. Each corresponding original dark WebP was the sole reference/edit target. Opaque output, no CLI/API fallback. The following prompts produced the selected variants; the website assets were subsequently resized and encoded as WebP.

## Core Defense

Use case: lighting-weather. Asset type: wide game artwork for hirrdirr.se light theme. Edit target: the supplied Core Defense night illustration. Create an intentionally designed DAYTIME companion to exactly this scene. Preserve the Japanese mountain setting, winding stone path, three goblins, two defensive turrets, cyan energy crystal at upper right, bridge, river and layered mountain silhouettes in essentially the same positions and framing. Change night to soft clear late-morning daylight: pale warm sky, misty blue-green distant mountains, sunlit sage foliage, readable stone, natural gentle shadows. Retain golden projectile streaks and cyan crystal detail, with restrained daylight glow. Detailed crisp pixel-art, same pixel density and illustrative style, full-bleed wide composition, approximately 2.53:1 aspect ratio (e.g. 1536 by 608). Designed to sit on warm ivory #eee9df. No text, titles, logos, borders, UI, collage or new objects. Do not merely brighten the night image; relight the entire environment naturally while preserving scene identity.
