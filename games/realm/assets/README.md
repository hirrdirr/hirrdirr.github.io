# Realm artwork

- cover.webp and cover-light.webp: original AI-generated artwork created for
  Project Realm with the built-in image generation tool on 2026-11-10.
  The light variant preserves the scene and changes its lighting.
  Encoded as WebP at quality 86; original generation was 1536 × 1024.
- realm-mark.svg and icons.svg: original code-native lantern and pixel icons.
  v0.3 adds branch, talent and ability symbols in the same SVG sprite sheet;
  no new raster assets or network requests are required for the talent system.
- In-world pixel art is authored in ../js/art.js; terrain art is in
  ../js/renderer.js. Original source-defined graphics, without third-party
  sprite packs, remote image dependencies or external asset attribution.
- No existing game's artwork, characters or world was used as a reference.

## Generation brief

Original cozy fantasy setting called Lantern Vale: a tiny half-timber village
with copper roofs and amber lanterns, a winding cobblestone path over a wooden
bridge crossing a teal river, emerald pine forest, an ancient broken beacon
with a cyan crystal, layered mountains, and a small cloaked traveler.
Detailed modern pixel art, clear silhouettes, crisp pixel clusters, emerald
and midnight teal with warm amber light; no lettering, UI or franchise assets.

The light variant changes lighting to soft morning daylight, an airy sky,
brighter grass and water, preserving composition and style.
